# Machine-Learning-Sports-Injury-Analysis
This project utilizes a Random Forest pipeline to classify athlete injury risk into three categories: Healthy, Low Risk, and High Risk. 

Work for HPC and Big Data Analysis of my MSc in Bioinformatics

# 📊 Methodology & Workflow
## 1. Data Preprocessing & PCA
- Feature Engineering: Selection of top physiological and workload predictors.
- Dimensionality Reduction: Implementation of PCA (Principal Component Analysis) to visualize class separation and variance.
- Normalization: Confusion matrices are normalized to show classification ratios across risk categories.

## 2. Feature Distribution Analysis
- Violin + Boxplot + Histogram: multimodal plot to capture statistical information.
- KDE Plots: densities showing the overlap and separation between the three injury risk classes.

## 3. Model Interpretation
- Feature Importance: ranking of variables.
- Confusion Matrices

# 🚀 Key Results
- Clear separation of High Risk profiles.
- Identified top predictors of injury using feature importance rankings.
- Meaningful graphics.
